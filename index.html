One project. Two detection modes.

The MATLAB application keeps face detection separate from the trained classifiers, so each mode uses its own model and class labels.

◉

Face detection

Detects faces in camera frames and draws bounding boxes around detected regions.

☺

Expression classification

Designed for Happy, Sad, and Neutral labels after the emotion model is trained and validated.

✓

Mask classification

Designed to classify Mask and No Mask with a confidence threshold and an uncertain result for weak predictions.

How the pipeline works

The application is modular, making it easier to demonstrate the engineering decisions during a college viva or placement interview.

01 · Capture

Read a frame from a compatible local webcam.

02 · Detect & preprocess

Locate face regions and prepare crops for the selected classifier.

03 · Classify & display

Show labels and confidence only when trained model files are available.

Run the actual application

The deployed page is the project showcase. Live camera inference runs in MATLAB on a desktop; this static page does not pretend to run MATLAB models in the browser.

  1. Download and extract the project ZIP above.
  2. Open MATLAB and set its Current Folder to the extracted project directory.
  3. Run checkVisionGuardSetup to inspect toolboxes, Compiler availability, models, and dataset folders.
  4. Prepare labelled training images as described in the repository README, then run trainVisionModels.
  5. Run runVisionGuard, allow webcam access, and test both modes.
  6. For a Windows executable, run deployVisionGuard after the models and MATLAB Compiler are available.

Important: Trained model files are not included yet. Emotion and mask classification will not produce real predictions until you train and validate the required models. MATLAB, compatible toolboxes, and webcam hardware are required. This project has not been represented as tested or deployment-verified.
